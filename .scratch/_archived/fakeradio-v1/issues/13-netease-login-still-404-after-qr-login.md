# 13 网易云扫码成功后仍出现 `Netease HTTP request failed: 404 Not Found`

## Problem

用户在播放器页完成网易云二维码扫码登录后，点击“检查登录”或后续音乐流程仍看到：

```text
Netease HTTP request failed: 404 Not Found
```

这说明“扫码登录成功”之后，FakeRadio 仍有某条调用本地 `NeteaseCloudMusicApi` 的路径会把 404 直接暴露给前端。当前需要先定位 404 的具体来源，再决定修复点。

## What we know

- FakeRadio 已新增网易云二维码登录接口：
  - `GET /api/netease/login/status`
  - `POST /api/netease/login/qr`
  - `GET /api/netease/login/qr/:key`
- 网易云 cookie 设计上保存到 `user/secrets/netease-cookie.txt`，后续 music adapter 请求会带 cookie。
- music resolve 设计上会优先请求 `/song/url/v1` 的高音质地址，再回退 `/song/url`。
- 用户实际复现：扫码成功后仍出现 `Netease HTTP request failed: 404 Not Found`。
- 当前还不确定 404 来自：
  - FakeRadio 登录检查接口；
  - `NeteaseCloudMusicApi` 的 `/login/status`、`/login/qr/check`；
  - 播放流程中的 `/cloudsearch`、`/song/url/v1`、`/song/url`；
  - 或者前端仍在请求旧 server / 旧 bundle。

## Evidence to collect

复现时需要记录以下信息，避免继续盲修：
