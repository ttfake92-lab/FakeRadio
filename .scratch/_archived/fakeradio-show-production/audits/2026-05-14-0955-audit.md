- 先让 `curl --noproxy '*' http://localhost:3302/` 返回页面，再重新做浏览器尺寸验收。

### P1: trace redaction 没有在写入 / 导出边界兜底

证据：

- `server/src/show/production-trace.ts:26` 定义 `redactSensitiveData()`。
- `server/src/show/show-generation-job.ts:268` 的 `addTrace()` 直接保存 entry。
- `server/src/show/show-project-repository.ts:232` 的 `appendTrace()` 直接 JSONL 追加 entry。
- `server/src/export/export-show-project.ts:179` 至 `:207` 合并 project trace 与 job trace 后直接写 `production-trace.jsonl`。

影响：

- 当前生成路径写入的 trace 摘要通常是安全摘要，但系统边界没有强制保护。
- 一旦 adapter / LLM / job 写入包含密钥、cookie、完整 system prompt 或私人记忆摘要的 trace，导出层会原样写入 `production-trace.jsonl`。

纠偏：

- 统一 trace writer 或在 `addTrace()` / `appendTrace()` 写入前 redaction。
- `exportShowProject()` 写导出 trace 前再次 redaction 兜底。
- 增加 export trace redaction 测试，覆盖密钥、cookie、system prompt、私人记忆摘要。
