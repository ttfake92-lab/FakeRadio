# 02 真实音乐来源与回退可用链路

## What to build

让 FakeRadio 的音乐来源在 adapter 边界内优先使用独立本地网易云服务，并在 provider 不可用时自动回退到 mock，同时通过 health 暴露当前运行状态。

这条 slice 是一条完整的端到端链路：本地 server 在启动时通过 provider 工厂选择音乐来源，真实 provider 可用时返回真实曲目，不可用时不断流地回退到 mock。播放器无需理解 provider 细节，只消费既有 contract。

## Acceptance criteria

- [ ] `MusicAdapter` 的 provider 选择由统一工厂负责，而不是分散在 route 中
- [ ] 本地网易云服务可用时，`/api/health` 返回 `adapters.music = "ready"`，`/api/next` 返回 `source = "netease"` 的真实曲目
- [ ] 本地网易云服务不可用时，FakeRadio 自动回退到 mock，且页面与基本播放流程不崩溃
