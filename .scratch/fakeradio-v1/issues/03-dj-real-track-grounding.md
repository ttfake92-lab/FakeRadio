## Parent

## What to build

让 DJ brain 在生成口播与理由时，真正引用当前真实曲目、候选队列、provider 工具结果和当前时段，而不是继续沿用 mock 语义描述。

完成后，用户在真实音乐来源可用时，不仅能听到真实歌曲，也能看到与当前歌曲和当前情境匹配的 DJ 解释。DJ 文案要保持陪伴感和节制，不变成机械播报。

## Acceptance criteria

- [ ] DJ 决策能使用真实 `music.search / resolve / queue` 结果作为 context fragments 的一部分
- [ ] 当真实 provider 可用时，DJ 文案与 `decision.reason` 不再错误声称“当前没有真实 provider 输入”
- [ ] 结构化 `DjDecision` 仍能通过 shared contract 校验
