## What to build

为 episode 生成链路接入公开音乐元数据来源，例如 MusicBrainz 和 Wikipedia。server 根据曲名与艺人查询公开资料，提取可验证的艺人、专辑、发行年份、风格或条目摘要，并把这些证据放入 `sources[]`。

当公开资料明确支持背景信息时，story composer 可以生成 `background` 类型故事；资料不足时必须降级为 `lyric-theme` 或 `mood-reading`。

## Acceptance criteria

- [ ] 新增公开元数据 source adapter，至少支持一个无需用户 API key 的公开资料源
- [ ] `GET /api/episode/next` 能把公开元数据摘要和来源 URL 放入 `sources[]`
- [ ] 只有存在明确公开资料时才允许返回 `story.type = "background"`
- [ ] 公开资料查询失败或匹配置信度不足时，episode 不失败，稳定降级
- [ ] 测试覆盖命中、未命中、低置信度匹配和 provider 失败路径
