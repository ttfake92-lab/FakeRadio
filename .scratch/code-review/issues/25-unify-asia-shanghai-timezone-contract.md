# 25 统一 Asia/Shanghai 时区契约，修复日期显示和归档偏移

## What to build

FakeRadio 当前多个地方依赖进程本地时区或直接使用 UTC ISO 日期：

- `server/src/scheduler/radio-scheduler.ts` 用 `now.toLocaleDateString("en-CA")` 生成今日计划日期，但没有指定 `timeZone`
- `server/src/user/session-repository.ts` 用 `date.toISOString().slice(0, 10)` 选择会话文件日期
- `server/src/export/export-pipeline.ts` 用 `date.toISOString().slice(0, 10)` 选择导出目录和下载文件日期
- `server/src/context/context-builder.ts` 把 `now.toISOString()` 注入 LLM prompt

这会导致 FakeRadio 在 Asia/Shanghai 的 00:00-07:59 之间，或在进程没有设置 `TZ=Asia/Shanghai` 时，显示/保存/导出到 UTC 前一天。DJ prompt 里的 `now` 也会呈现 UTC 时间，容易让模型误判当前时段。

需要建立统一的本地电台时间契约，默认使用 `Asia/Shanghai`，所有“今日”“当前时段”“会话日期”“导出日期”“LLM 环境时间”都走同一套 formatter。
